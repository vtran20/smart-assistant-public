Use when asked directly to delegate engineering work, or when an ordinary request
has independent substantial parts requiring specialist coordination. Assess value
before dispatch: small coherent work uses a direct workflow. Unrelated writing,
employee support and factual questions do not trigger engineering delegation.
Missing essential input, authorized ownership, tools, configured native roles or
independent review gives an explicit blocker and next step.

Read [bounded delegation workflow](references/workflow.md) before dispatch.
Follow design → implement → independent review → feedback → test → repeat until
acceptance passes. Produce scoped assignments and actual v1 handoffs, child review
and feedback evidence, fresh checks and a combined reviewable result. Keep failures
and partial results saved. Only the coordinator changes durable parent state and
requests completion using the real gate.

Source validation and isolated tests establish structure only. Keep managed assets
DRAFT until genuine native discovery/invocation and manifest-bound behavioral
observations support activation. Do not infer activation from file presence,
fixtures or an invented tool. Inherit model and effort. This workflow grants no
new permissions, account access, publishing, messages or recurring work.
