## Scope and knowledge

The [current definition](../examples/agents/xstore-triage/versions/1.0.1/xstore-triage.toml)
assesses only selected, supplied Xstore build, configuration, runtime, UI, SQL
packaging and OPI evidence. It returns an eleven-field source-grounded assessment,
separate proof gates, essential blockers and concrete next evidence questions for
independent review. It performs no customer build/generation/startup, SQL, payment,
trust, network or source/configuration changes and spawns no children. Instructions
constrain behavior; the host enforces permissions. No extra read-only sandbox is claimed.

The complete [procedural pack 1.0.0](../examples/agents/xstore-triage/knowledge/1.0.0/pack.json)
is embedded in the TOML and bound by the complete deployment manifest. Eight
procedures derive from seven inspected, pinned user-owned guidance sources. The
pack contains no customer settings, private source paths or fixed release/JDK
compatibility facts. Its immutable candidate-at-authoring state is unchanged;
source validation is not knowledge promotion, vendor authority or human acceptance.

> smallest next read-only evidence. Do not build, restart or change customer files.

actual tool availability, exact version/manifest and scoped preflight. An advisory
