## Approach and dependencies

Use the approved local standard-library helpers and installed Codex client. Add integration regressions and a narrowly scoped isolated native-evaluation adapter. Reusing package tests alone would miss composition errors; a new backend or scheduler would expand scope. Tests exercise actual public APIs/CLI with disposable projects/state and unmistakably hypothetical review/native receipts. Native observations use genuine fresh installed-client sessions and copied exact current helper/native sources, scoped fixtures and an explicit finite prompt. Prior evaluations support provenance but never substitute for fresh P09 observations.

Before mutation, validate current catalog15/six eligible capabilities and all accepted P08 core hashes, run baseline293 tests, pin existing private files and worktrees. Ordinary managed dispatch still requires exact current identities, dependencies and preflight; source-evaluation fixture roles/skills are not falsely represented as canonical managed selection. No account actions, publication, messages to other chats, recurring work or canonical capability lifecycle mutation is authorized by this package. Newly added lifecycle fixtures remain isolated and are clearly distinguished from the six canonical ACTIVE capabilities.
